# Support

Use [GitHub Issues](https://github.com/CruxExperts/best-backup/issues) for bugs and feature requests. Identify whether you are using the retained 1.x commands or the `bbackup production` v2 preview.

For a bug report, include the bbackup version, Linux distribution, Python version, command, storage type, and a short description of the expected and observed behavior. Remove passwords, access keys, repository URLs with credentials, personal data, and sensitive file paths before posting configuration or output. Never attach host bindings or credential files.

Version 2 is a preview, not a production-qualified release. B2/AWS provider protection and thirty-day independent recovery remain unqualified; see [preview evidence and limits](docs/development/version-2.md).

For a security vulnerability, do not open a public issue. Follow the private process in [SECURITY.md](SECURITY.md).
