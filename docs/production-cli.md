# Production command reference

> Generated by `scripts/generate_cli_skills.py` from `bbackup/cli_metadata.py`.

The command contract is stable in v2.0.3. Production qualification remains limited to the tested scope in [version 2 release evidence](development/version-2.md).

Prefix commands with `bbackup production --config CONFIG --bindings BINDINGS`.

All operation commands emit one schema-version-2 JSON result. Use `--schema` for the input contract.

## `doctor`

Inspect configured repository bindings and engine availability.


## `setup`

Validate and create new version-three policy and private bindings, or explicitly migrate or enroll an existing pair without enabling services.

- `--configuration-file`: optional-string.
- `--bindings-file`: optional-string.
- `--migrate`: boolean.
- `--enroll`: boolean.

## `config show`

Read portable configuration and its revision without exposing private bindings.


## `config save`

Validate and replace the portable configuration only at its reviewed revision, preserving a private backup.

- `--document-file`: path.
- `--revision`: string.

## `config migrate`

Write enrolled version-three files beside untouched version-two originals.


## `service enroll`

Explicitly enroll the exact version-three policy and bindings on this machine and user.


## `jobs list`

List configured capture jobs.


## `jobs run`

Capture locally and copy explicit successful snapshots.

- `--name`: string.

## `repositories list`

List declared repositories without host credentials.


## `repositories init`

Initialize an encrypted repository.

- `--name`: string.
- `--source`: optional-string.

## `repositories check`

Read and verify repository data.

- `--name`: string.

## `snapshots list`

List successful local snapshot receipts.

- `--limit`: limit.
- `--offset`: offset.

## `snapshots copy`

Copy a successful snapshot into an independent repository.

- `--source`: string.
- `--destination`: string.
- `--snapshot`: string.

## `retention plan`

Review a read-only local retention plan bound to current snapshot and replica evidence.

- `--job`: string.

## `retention apply`

Apply only a reviewed local retention plan after explicit approval; never prunes repository data.

- `--job`: string.
- `--plan-token`: string.
- `--approved`: boolean.

## `cloud-retention catalog-enroll`

Explicitly enroll a new central exact-version retention catalog; never replace a missing established catalog.

- `--repository`: string.
- `--policy-file`: path.
- `--grant-file`: path.

## `cloud-retention plan`

Plan noncurrent object-version deletion from independently accepted checkpoints and private authority.

- `--repository`: string.
- `--policy-file`: path.
- `--grant-file`: path.
- `--records-file`: path.
- `--quiescent-window-confirmed`: boolean.

## `cloud-retention apply`

Apply one reviewed exact-version plan under the shared repository lease; never replay uncertain deletes.

- `--repository`: string.
- `--policy-file`: path.
- `--grant-file`: path.
- `--records-file`: path.
- `--plan-id`: string.
- `--plan-sha256`: string.
- `--quiescent-window-confirmed`: boolean.

## `cloud-retention reconcile`

Reconcile a cloud-version deletion journal using read-only observations without replaying it.

- `--repository`: string.
- `--policy-file`: path.
- `--plan-file`: path.

## `restore`
