# Production preview command reference

> Generated by `scripts/generate_cli_skills.py` from `bbackup/cli_metadata.py`.

These commands are a development preview, not a qualified 2.0 release.

Prefix commands with `bbackup production --config CONFIG --bindings BINDINGS`.

All operation commands emit one schema-version-2 JSON result. Use `--schema` for the input contract.

## `doctor`

Inspect configured repository bindings and engine availability.


## `jobs list`

List configured capture jobs.


## `jobs run`

Capture locally and copy explicit successful snapshots.

- `--name`: string.

## `repositories list`

List declared repositories without host credentials.


## `repositories init`

Initialize an encrypted repository.

- `--name`: string.
- `--source`: optional-string.

## `repositories check`

Read and verify repository data.

- `--name`: string.

## `snapshots list`

List successful local snapshot receipts.

- `--limit`: limit.
- `--offset`: offset.

## `snapshots copy`

Copy a successful snapshot into an independent repository.

- `--source`: string.
- `--destination`: string.
- `--snapshot`: string.

## `restore`

Restore and verify files in a new isolated directory.

- `--repository`: string.
- `--snapshot`: string.
- `--target`: path.

## `runs list`

Read sanitized operation events.

- `--limit`: limit.
- `--offset`: offset.

## `service render`

Render disabled systemd service and persistent timer units.

- `--name`: string.
- `--executable`: path.

## `recovery inspect`

Inspect cloud versioning and lifecycle without a protection claim.

- `--bucket`: string.
- `--endpoint`: string.
- `--prefix`: optional-string.
- `--region`: optional-string.

## `recovery checkpoint`

Check a quiescent repository and seal an independent recovery kit.

- `--repository`: string.
- `--snapshot`: string.
- `--bucket`: string.
- `--endpoint`: string.
- `--prefix`: optional-string.
- `--region`: optional-string.
- `--target`: path.
- `--signer`: string.
- `--recipient`: string.
- `--quiescent-window-confirmed`: boolean.

## `recovery open`

Authenticate and decrypt a recovery kit into a new private directory.

- `--kit`: path.
- `--target`: path.
- `--signer`: string.

## `recovery restore`

Restore signed exact historical object versions into a new local repository.

- `--manifest`: path.
- `--signature`: path.
- `--signer`: string.
- `--password-file`: path.
- `--repository`: string.
- `--repository-id`: string.
- `--snapshot`: string.
- `--bucket`: string.
- `--endpoint`: string.
- `--prefix`: optional-string.
- `--region`: optional-string.
- `--target`: path.

## `runs stream`

Emit a bounded page of lifecycle events as explicit JSON lines, without a result envelope.

- `--limit`: limit.
- `--offset`: offset.

## `skills`

Discover the production operation registry and generated input schemas.

- `--name`: optional-string.

## `runs reconcile`

Record an administrator-reviewed outcome for an uncertain operation without replaying it.

- `--repository`: string.
- `--operation-id`: string.
- `--outcome`: string.
- `--repository-reviewed`: boolean.

## `databases restore`

Restore a trusted PostgreSQL snapshot export into a new database and validate connectivity.

- `--repository`: string.
- `--snapshot`: string.
- `--source`: string.
- `--connection`: string.
- `--target-database`: string.
- `--trusted-archive`: boolean.

## `databases reconcile`

Record an administrator-reviewed database restore outcome without replaying it.

- `--connection`: string.
- `--target-database`: string.
- `--operation-id`: string.
- `--outcome`: string.
- `--database-reviewed`: boolean.

## `recovery b2-inspect`

Inspect a Backblaze B2 bucket using its vendor SDK, bounded retries, and environment credentials.

- `--bucket`: string.
- `--prefix`: optional-string.
- `--key-id-env`: optional-string.
- `--key-env`: optional-string.
